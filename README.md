# EduBridge

A bilingual, responsive educational-opportunities concept website built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a GitHub account if you do not already have one.
2. Create a **public** repository named `edubridge`.
3. Upload `index.html` (and this README if desired).
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then Save.
7. Wait for the published website link to appear in the Pages section.

## Important
The opportunity cards are demonstration categories, not verified live scholarship listings. Replace them with researched, accurate information before presenting the site as a live scholarship directory.

## Project description
EduBridge is a bilingual student-focused concept platform that organizes educational pathways, scholarship research categories, volunteering information, and learning tracks in one responsive interface.
